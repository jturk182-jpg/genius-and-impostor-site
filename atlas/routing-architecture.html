The Access Line

Routing Architecture

Your brain operates in different modes, like focused work, mind-wandering, and sleep. Each mode changes which parts of the brain can communicate. The book calls the pattern of connections in each mode its routing architecture. Changing modes changes what you can reach, without changing anything you know.
